# Dart Learning Practice

A collection of my Dart programming exercises from learning sessions with Pa Devi, focusing on Object-Oriented Programming (OOP) concepts.

## Learning Topics

- **Classes and Objects** — Understanding classes, properties, and object instances.
- **Methods** — Creating methods to define object behavior.
- **Constructors** — Learning default, parameterized, and named constructors.
- **Object Interaction** — Implementing methods to manage object data and behavior.
- **Getters** — Using getters to calculate and retrieve values.
- **Conditional Statements** — Applying conditions to determine program results.
- **Lists and Calculations** — Working with lists, calculating averages, and determining student grades.

## Practice Exercises

This repository contains six Dart practice files:

1. **Mobil** — Creating objects with different properties such as brand, color, and maximum speed.
2. **Hewan** — Implementing methods to display animal names, types, and sounds.
3. **ProdukToko** — Using constructors and methods to calculate total product prices.
4. **Karyawan** — Exploring parameterized and named constructors.
5. **Buku** — Implementing borrowing and returning book functionality.
6. **Siswa** — Calculating average scores and determining student grades.

## Purpose

This repository serves as a personal learning archive to document my understanding of Dart and Object-Oriented Programming through coding exercises and practice.
